# Developer themes implementation plan

**Goal:** Isolate the app's visual language and ship native Default and TRON: Legacy-inspired themes.

**Architecture:** Keep theme definitions and reusable SwiftUI styling in `Sources/DotListPlusUI/DesignSystem`. Inject one theme above navigation and sheets. Keep work rules, storage, and sync unchanged.

**Tech stack:** Existing SwiftUI package; iOS 17+, macOS 14+; no dependencies.

**Design:** Default follows system appearance, typography, controls and semantic colors. TRON uses near-black surfaces, cyan illuminated edges/dots, amber next-action accents, and brief interaction animations. Respect Reduce Motion; keep text readable without glow. Theme selection is developer-controlled, with Default shipped and an Xcode environment override for TRON. No settings picker or persisted theme preference.
